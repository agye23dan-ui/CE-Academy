## Section B solutions

**B1.** Step 1: factor the denominator: x² + x - 6 = (x + 3)(x - 2).
Step 2: partial fractions: (x + 1)/((x + 3)(x - 2)) = A/(x + 3) + B/(x - 2), so x + 1 = A(x - 2) + B(x + 3).
Step 3: x = -3: -2 = -5A, so A = 2/5. x = 2: 3 = 5B, so B = 3/5.
Step 4: integrate: **(2/5) ln|x + 3| + (3/5) ln|x - 2| + C**.

**B2.** The points are A(1, 0, 0), B(0, 2, 0), C(0, 0, 3).
Step 1: the intercept form of a plane is x/1 + y/2 + z/3 = 1.
Step 2: multiply by 6: 6x + 3y + 2z = 6.
Step 3 (check): A: 6(1) = 6 ✓; B: 3(2) = 6 ✓; C: 2(3) = 6 ✓. **6x + 3y + 2z = 6**.
Step 4: distance from the origin = |0 - 6|/√(36 + 9 + 4) = 6/√49 = **6/7 ≈ 0.857**.

**B3.** z = x² + y² with x = cos t, y = sin t.
Step 1: chain rule: dz/dt = z_x dx/dt + z_y dy/dt = 2x(-sin t) + 2y(cos t).
Step 2: substitute: 2 cos t (-sin t) + 2 sin t cos t = -2 sin t cos t + 2 sin t cos t = **0**.
Check: z = cos²t + sin²t = 1 is constant (the point moves on the unit circle where x² + y² = 1).

**B4.** The region is bounded by y = 0, x = 1 and the line y = 2x (the inner limit x = y/2), so 0 ≤ y ≤ 2 and y/2 ≤ x ≤ 1, equivalently 0 ≤ x ≤ 1 and 0 ≤ y ≤ 2x. e^(x²) has no elementary antiderivative in x, so integrate over y first.
Step 1: ∫₀¹ ∫₀^(2x) e^(x²) dy dx = ∫₀¹ e^(x²) [y]₀^(2x) dx = ∫₀¹ 2x e^(x²) dx.
Step 2: let u = x², du = 2x dx: ∫₀¹ e^u du = [e^u]₀¹ = e - 1.
**e - 1 ≈ 1.718**.

**B5.** F = (y, x²) along y = x², from (0, 0) to (1, 1).
Step 1: parametrise by x: y = x², dy = 2x dx.
Step 2: ∫ F · dr = ∫ y dx + x² dy = ∫₀¹ (x² + x² · 2x) dx = ∫₀¹ (x² + 2x³) dx.
Step 3: = [x³/3 + x⁴/2]₀¹ = 1/3 + 1/2 = **5/6**.

**B6.** dy/dx = 1 + y², y(0) = 0.
Step 1: separate: dy/(1 + y²) = dx.
Step 2: integrate: arctan y = x + C. y(0) = 0 gives arctan 0 = 0 = C.
Step 3: y = tan x. It is defined and finite for -π/2 < x < π/2 (it blows up at x = ±π/2). **y = tan x on (-π/2, π/2)**.

**B7.** y'' - 4y' + 4y = 0, y(0) = 1, y'(0) = 0.
Step 1: λ² - 4λ + 4 = (λ - 2)² = 0: repeated root 2, so y = (c₁ + c₂x)e^(2x).
Step 2: y(0) = c₁ = 1.
Step 3: y' = c₂e^(2x) + 2(c₁ + c₂x)e^(2x), so y'(0) = c₂ + 2c₁ = c₂ + 2 = 0 and c₂ = -2.
**y = (1 - 2x)e^(2x)**.

**B8.** Step 1: L{cos 3t} = s/(s² + 9). Step 2: first shift theorem: replace s by s + 2 for multiplication by e^(-2t). **L{e^(-2t) cos 3t} = (s + 2)/((s + 2)² + 9)**.

## Section C solutions

**C1.** Plane x + 2y + 3z = 14 and the origin.
(a) Step 1: minimise f = x² + y² + z² subject to g = x + 2y + 3z = 14. ∇f = λ∇g: (2x, 2y, 2z) = λ(1, 2, 3).
Step 2: x = λ/2, y = λ, z = 3λ/2, i.e. (x, y, z) = (λ/2)(1, 2, 3).
Step 3: constraint: (λ/2)(1 + 4 + 9) = 14, so 7λ = 14 and λ = 2.
Step 4: **the point is (1, 2, 3)**.
(b) Step 1: f(1, 2, 3) = 1 + 4 + 9 = 14. Step 2: the minimum distance is √14 = **3.742**.
(c) Step 1: the sphere x² + y² + z² = 14 contains (1, 2, 3) since 1 + 4 + 9 = 14.
Step 2: its gradient there is (2, 4, 6) = 2(1, 2, 3), parallel to the plane's normal (1, 2, 3).
Step 3: so the tangent plane of the sphere at (1, 2, 3) is (1, 2, 3) · (x - 1, y - 2, z - 3) = 0, i.e. x + 2y + 3z = 14, the given plane. The plane is **tangent** to the sphere.
(d) Step 1: distance formula: |0 + 0 + 0 - 14|/√(1 + 4 + 9) = 14/√14 = √14 ✓, agreeing with (b).

**C2.** Solid inside the cone z = r, below the plane z = 2 (a cone of radius 2 and height 2).
(a) Step 1: V = ∫₀^(2π) ∫₀² ∫_r² r dz dr dθ.
Step 2: ∫_r² dz = 2 - r, so ∫₀² r(2 - r) dr = [r² - r³/3]₀² = 4 - 8/3 = 4/3.
Step 3: V = 2π(4/3) = **8π/3 ≈ 8.38**.
Check: cone volume (1/3)πR²h = (1/3)π(4)(2) = 8π/3 ✓.
(b) Step 1: ∭ z dV = ∫₀^(2π) ∫₀² r [z²/2]_r² dr dθ = 2π ∫₀² r(4 - r²)/2 dr.
Step 2: ∫₀² (4r - r³) dr = [2r² - r⁴/4]₀² = 8 - 4 = 4, so the integral is 2π · (1/2) · 4 = 4π.
Step 3: z̄ = (4π)/(8π/3) = 12π/(8π) = **3/2**.
Check: for a cone with its apex at the origin the centroid is at 3/4 of the height: (3/4)(2) = 1.5 ✓.
(c) Step 1: the cone z = r corresponds to φ = π/4 (since tan φ = r/z = 1), and the plane z = 2 is ρ cos φ = 2, i.e. ρ = 2/cos φ.
Step 2: **V = ∫₀^(2π) ∫₀^(π/4) ∫₀^(2/cos φ) ρ² sin φ dρ dφ dθ**.

**C3.** ∮ xy dx + x² dy around the triangle (0, 0), (1, 0), (1, 1).
(a) Edge C₁: (0, 0) → (1, 0): y = 0, dy = 0, so xy dx + x² dy = 0. Contribution 0.
Edge C₂: (1, 0) → (1, 1): x = 1, dx = 0, so the integrand is x² dy = dy. ∫₀¹ dy = 1.
Edge C₃: (1, 1) → (0, 0) along y = x: dy = dx, integrand = x·x dx + x² dx = 2x² dx. ∫ from x = 1 to x = 0 of 2x² dx = -2/3.
Total: 0 + 1 - 2/3 = **1/3**.
(b) Step 1: Green's theorem: ∮ P dx + Q dy = ∬ (Q_x - P_y) dA with P = xy, Q = x².
Step 2: Q_x - P_y = 2x - x = x.
Step 3: the region is 0 ≤ y ≤ x, 0 ≤ x ≤ 1: ∬ x dA = ∫₀¹ x · x dx = ∫₀¹ x² dx = **1/3** ✓ (agrees with (a)).
(c) The line integral equals the double integral of the scalar curl. If Q_x - P_y were 1 the double integral would be the area of the region. Taking P = -y/2, Q = x/2 gives Q_x - P_y = 1, so ∮ (x dy - y dx)/2 = area (here 1/2 for this triangle): a line-integral formula for area.

**C4.** y'' + 2y' + 5y = 5u(t) with zero initial conditions.
(a) Step 1: transform: (s² + 2s + 5)Y = 5/s (since L{u(t)} = 1/s).
Step 2: transfer function (output/input with U = 1/s): **G(s) = 5/(s² + 2s + 5)**.
Step 3: poles: s = -1 ± 2i. Natural frequency ω_n = √5 and damping ratio ζ = 2/(2√5) = 1/√5 ≈ 0.447, so the system is **underdamped and stable**.
(b) Step 1: Y = 5/(s(s² + 2s + 5)) = A/s + (Bs + C)/(s² + 2s + 5). 5 = A(s² + 2s + 5) + (Bs + C)s. s = 0: A = 1. s² coefficient: 0 = A + B so B = -1; s coefficient: 0 = 2A + C so C = -2.
Step 2: Y = 1/s - (s + 2)/(s² + 2s + 5) = 1/s - [(s + 1) + 1]/((s + 1)² + 4).
Step 3: invert: (s + 1)/((s + 1)² + 4) → e^(-t) cos 2t; 1/((s + 1)² + 4) = (1/2) · 2/((s + 1)² + 4) → (1/2) e^(-t) sin 2t.
**y(t) = 1 - e^(-t)(cos 2t + (1/2) sin 2t)**.
Check: y(0) = 1 - 1 = 0 ✓; y'(t) = (5/2) e^(-t) sin 2t, so y'(0) = 0 ✓.
(c) Step 1 (final value): e^(-t) → 0, so y(∞) = **1** (also G(0) = 5/5 = 1).
Step 2 (peak): y' = 0 first at sin 2t = 0, t = π/2 ≈ 1.571 s.
Step 3: y(π/2) = 1 - e^(-π/2)(cos π + 0) = 1 + e^(-π/2) = 1 + 0.2079 = 1.208.
Step 4: percentage overshoot = (1.208 - 1)/1 = **20.8 percent**. This matches exp(-πζ/√(1 - ζ²)) = exp(-π(0.447)/0.894) = e^(-π/2) ✓.
Step 5: 2 percent settling time ≈ 4/(ζω_n) = 4/1 = 4 s.

**C5.** Two-tank system x' = A x with A = [[-3, 1],[2, -2]].
(a) Step 1: characteristic equation det(A - λI) = (-3 - λ)(-2 - λ) - (1)(2) = λ² + 5λ + 6 - 2 = λ² + 5λ + 4 = 0.
Step 2: (λ + 1)(λ + 4) = 0, so **λ = -1, -4**.
Step 3: λ = -1: A + I = [[-2, 1],[2, -1]]; -2v₁ + v₂ = 0, so v = (1, 2).
Step 4: λ = -4: A + 4I = [[1, 1],[2, 2]]; v₁ + v₂ = 0, so v = (1, -1).
(b) Step 1: x = c₁e^(-t)(1, 2) + c₂e^(-4t)(1, -1).
Step 2: x(0) = (3, 0): c₁ + c₂ = 3 and 2c₁ - c₂ = 0. Adding: 3c₁ = 3, so c₁ = 1 and c₂ = 2.
**x(t) = (e^(-t) + 2e^(-4t), 2e^(-t) - 2e^(-4t))**.
Check: x(0) = (3, 0) ✓; x'(0) = (-1 - 8, -2 + 8) = (-9, 6) and A x(0) = (-3·3 + 0, 2·3 + 0) = (-9, 6) ✓.
(c) Both eigenvalues are real and negative, so the origin is a **stable node**. Every solution decays to zero; for large t the slower mode (λ = -1) dominates, so trajectories approach the origin along the direction (1, 2).

### Section A

Brief reasons:
1. Step 1: antiderivative of e^(-2x) is -e^(-2x)/2. Step 2: evaluate: [-e^(-2x)/2] from 0 to ∞ = 0 - (-1/2) = 1/2.
2. Step 1: let u = x², du = 2x dx. Step 2: ∫ x e^(x²) dx = (1/2) ∫ e^u du = (1/2) e^(x²) + C.
3. Step 1: A = (1/2) ∫ r² dθ over 0 to 2π. Step 2: r = 2, so A = (1/2)(4)(2π) = 4π.
4. Step 1: a · b = (1)(4) + (2)(0) + (3)(-1). Step 2: = 4 + 0 - 3 = 1.
5. Step 1: a = (1, 0, 0) and b = (0, 2, 0) are perpendicular, so |a × b| = |a||b| sin 90° = (1)(2)(1) = 2. Step 2 (by components): a × b = (0, 0, 2), magnitude 2.
6. Step 1: plane with normal n through the origin: n · r = 0. Step 2: (1, 1, 1) · (x, y, z) = x + y + z = 0.
7. Step 1: f_x = 2xy. Step 2: differentiate with respect to y: f_xy = 2x.
8. Step 1: ∇f = (2x, 2y). Step 2: at (1, 1): (2, 2).
9. Step 1: second derivative test: D < 0 means f_xx and f_yy have opposite curvature in different directions. Step 2: that is a saddle point.
10. Step 1: ∬ 6xy dA = 6 (∫₀¹ x dx)(∫₀¹ y dy). Step 2: = 6 (1/2)(1/2) = 3/2.
11. Step 1: polar coordinates have Jacobian r. Step 2: dA = r dr dθ.
12. Step 1: spherical Jacobian is ρ² sin φ. Step 2: dV = ρ² sin φ dρ dφ dθ.
13. Step 1: div F = ∂x/∂x + ∂y/∂y + ∂z/∂z. Step 2: = 1 + 1 + 1 = 3.
14. Step 1: curl(∇f) has components like f_zy - f_yz. Step 2: mixed partials are equal, so every component is 0: the zero vector.
15. Step 1: separate: dy/y = dx. Step 2: ln|y| = x + c, so y = C eˣ.
16. Step 1: for y' + P y = Q the integrating factor is e^(∫P dx). Step 2: P = 2, so e^(2x).
17. Step 1: characteristic equation λ² - 5λ + 6 = 0. Step 2: factor (λ - 2)(λ - 3) = 0, so λ = 2, 3.
18. Step 1: the forcing frequency equals the natural frequency ω₀. Step 2: the particular solution is (t/(2ω₀)) sin ω₀t, whose amplitude grows linearly: resonance.
19. Step 1: L{e^(at)} = 1/(s - a). Step 2: with a = 3: 1/(s - 3).
20. Step 1: L{y'} = sY - y(0). Step 2: apply again: L{y''} = s(sY - y(0)) - y'(0) = s²Y - s y(0) - y'(0).

### Section B

**B1.**
(a) Step 1: cos³x = cos x (1 - sin²x) (save one cosine).
Step 2: let u = sin x, du = cos x dx: ∫ (1 - u²) du = u - u³/3.
**sin x - sin³x/3 + C**.
(b) Step 1: partial fractions: 1/((x - 2)(x + 1)) = A/(x - 2) + B/(x + 1), so 1 = A(x + 1) + B(x - 2).
Step 2: x = 2: 1 = 3A, A = 1/3. x = -1: 1 = -3B, B = -1/3.
Step 3: ∫ = (1/3) ln|x - 2| - (1/3) ln|x + 1|. **(1/3) ln|(x - 2)/(x + 1)| + C**.
(c) Step 1: by parts with u = x, dv = e^(-x) dx: du = dx, v = -e^(-x). ∫ x e^(-x) dx = -x e^(-x) + ∫ e^(-x) dx = -x e^(-x) - e^(-x).
Step 2: evaluate [-x e^(-x) - e^(-x)] from 0 to ∞. At ∞: x e^(-x) → 0 and e^(-x) → 0, so the value is 0. At 0: -0 - 1 = -1.
Step 3: 0 - (-1) = **1**.
(d) Step 1: A = (1/2) ∫₀^(2π) (1 + cos θ)² dθ = (1/2) ∫ (1 + 2 cos θ + cos²θ) dθ.
Step 2: ∫₀^(2π) 1 dθ = 2π, ∫ cos θ dθ = 0, ∫ cos²θ dθ = π.
Step 3: A = (1/2)(2π + 0 + π) = **3π/2**.

**B2.** f = x² + xy + y² - 3x.
(a) Step 1: f_x = 2x + y - 3 = 0 and f_y = x + 2y = 0.
Step 2: from the second equation x = -2y. Substitute: 2(-2y) + y - 3 = -3y - 3 = 0, so y = -1 and x = 2. Critical point (2, -1).
Step 3: f_xx = 2, f_yy = 2, f_xy = 1. D = f_xx f_yy - f_xy² = 4 - 1 = 3 > 0 and f_xx = 2 > 0: **local (and global) minimum**.
Step 4: f(2, -1) = 4 - 2 + 1 - 6 = **-3**.
(b) f = xy at (2, 1): f = 2, f_x = y = 1, f_y = x = 2.
Tangent plane: z = 2 + 1(x - 2) + 2(y - 1) = x + 2y - 2. **z = x + 2y - 2**.
(c) Minimise f = x² + y² subject to g = x + y = 4.
Step 1: ∇f = λ∇g: (2x, 2y) = λ(1, 1), so 2x = 2y = λ and x = y.
Step 2: x + y = 4 gives x = y = 2.
Step 3: minimum value f = 4 + 4 = **8** at (2, 2).

**B3.**
(a) Step 1: the region is 0 ≤ y ≤ x, 0 ≤ x ≤ 1. Inner integral: ∫₀ˣ xy dy = x[y²/2]₀ˣ = x · x²/2 = x³/2.
Step 2: outer: ∫₀¹ x³/2 dx = (1/2)(1/4) = **1/8**.
(b) Step 1: the paraboloid z = 4 - r² meets z = 0 at r = 2.
Step 2: V = ∫₀^(2π) ∫₀² (4 - r²) r dr dθ.
Step 3: ∫₀² (4r - r³) dr = [2r² - r⁴/4]₀² = 8 - 4 = 4.
Step 4: V = 2π(4) = **8π ≈ 25.13**.
(c) Step 1: ∬ x² + y² dA over the disc of radius 2 = ∫₀^(2π) ∫₀² r² · r dr dθ.
Step 2: ∫₀² r³ dr = 16/4 = 4.
Step 3: = 2π(4) = **8π**.

**B4.**
(a) y' + 2y = 6.
Step 1: integrating factor e^(2x): (e^(2x) y)' = 6e^(2x).
Step 2: integrate: e^(2x) y = 3e^(2x) + C.
Step 3: y(0) = 0: 0 = 3 + C, so C = -3. y = 3 - 3e^(-2x). **y = 3(1 - e^(-2x))**.
(b) y'' + 2y' + 5y = 0.
Step 1: λ² + 2λ + 5 = 0, λ = [-2 ± √(4 - 20)]/2 = -1 ± 2i.
Step 2: y = e^(-x)(c₁ cos 2x + c₂ sin 2x). y(0) = c₁ = 1.
Step 3: y' = e^(-x)[(-c₁ + 2c₂) cos 2x + (-c₂ - 2c₁) sin 2x]; y'(0) = -c₁ + 2c₂ = 0, so c₂ = 1/2.
**y = e^(-x)(cos 2x + (1/2) sin 2x)**.
(c) y' + 2y = e^(-t), y(0) = 0.
Step 1: transform: sY - 0 + 2Y = 1/(s + 1), so (s + 2)Y = 1/(s + 1).
Step 2: Y = 1/((s + 1)(s + 2)). Partial fractions: 1/((s + 1)(s + 2)) = 1/(s + 1) - 1/(s + 2).
Step 3: invert: **y = e^(-t) - e^(-2t)**.
Check: y(0) = 0 ✓; y' + 2y = (-e^(-t) + 2e^(-2t)) + (2e^(-t) - 2e^(-2t)) = e^(-t) ✓.

## Section B: Short Questions (40 marks)

**B1. NPV and IRR (5 marks)** A project costs $100,000 and returns $30,000 per year for 5 years; MARR = 10 percent. Compute the NPV and say whether to accept (IRR = 15.2 percent).

**B2. Depreciation (5 marks)** An asset costs $20,000, salvage $2,000, life 4 years. Give the straight-line depreciation and the double-declining-balance depreciation for each year.

**B3. Inventory (5 marks)** Annual demand 10,000, ordering cost $40, holding cost $2/unit-year. Find the EOQ and the number of orders per year.

**B4. PERT (5 marks)** A task has optimistic 3, most likely 5 and pessimistic 13 weeks. Compute the expected duration and standard deviation, and explain why the mean exceeds the most likely value.

**B5. Control chart (5 marks)** Six subgroups of 4 have means 25.1, 24.9, 25.2, 25.0, 24.8, 25.1 and ranges 0.5, 0.6, 0.4, 0.7, 0.5, 0.6. Compute the X-bar chart limits and the R-chart upper limit.

**B6. Queue (5 marks)** Arrivals 8/h, each server handles 5/h. For 2 servers the probability of waiting is 0.711 and for 3 servers 0.274. Compute utilization and the mean wait for 2 and 3 servers (W_q = P/(cμ - λ)).

**B7. Loan (5 marks)** A $30,000 equipment loan at 7 percent is repaid in 5 equal yearly payments. Find the payment and the total interest.

**B8. Learning curve (5 marks)** An 85 percent learning curve applies to a task whose first unit takes 200 hours. How long does the 4th unit take?

### Section B

**B1.** NPV = -100,000 + 30,000 × 3.7908 = **+$13,724**; positive and the IRR (15.2 percent) exceeds the MARR (10 percent): **accept** [5].

**B2.** Straight line = (20,000 - 2,000)/4 = **$4,500**/year [2]. DDB (rate 50 percent of opening book value): year 1: **10,000** (BV 10,000); year 2: **5,000** (BV 5,000); year 3: **2,500** (BV 2,500); year 4: 1,250 would take BV below salvage, so only **500** (to reach $2,000) [3].

**B3.** EOQ = √(2 × 10,000 × 40/2) = **632 units**; orders per year = 10,000/632 = **15.8** [5].

**B4.** Expected = (3 + 4 × 5 + 13)/6 = **6.0 weeks**; σ = (13 - 3)/6 = **1.67 weeks** [3]. The mean exceeds the most likely value because the distribution is skewed to the right (the pessimistic tail is longer than the optimistic one) [2].

**B5.** x̿ = 25.017; R̄ = 0.55. X-bar UCL = 25.017 + 0.729 × 0.55 = **25.418**; LCL = **24.616** [3]. R-chart UCL = D₄R̄ = 2.282 × 0.55 = **1.255** [2].

**B6.** c = 2: ρ = 8/10 = **0.80**; W_q = 0.711/(10 - 8) = 0.356 h = **21.3 min**. c = 3: ρ = 8/15 = **0.53**; W_q = 0.274/(15 - 8) = 0.039 h = **2.3 min** [5].

**B7.** A = 30,000 × 0.07/(1 - 1.07⁻⁵) = **$7,317**; total paid = 36,583; interest = **$6,583** [5].

**B8.** Time per unit for unit n = T₁ n^(log 0.85/log 2) → unit 4 = 200 × 0.85² = **144.5 hours** (each doubling multiplies the unit time by 0.85; 1 → 2 → 4) [5].

### Section C

**C1.**
(a) X: NPV = -100,000 + 30,000 × 3.7908 = **$13,724**; IRR = **15.2 percent**; B/C = 113,724/100,000 = **1.137**. Y: NPV = -60,000 + 20,000 × 3.7908 = **$15,816**; IRR = **19.9 percent**; B/C = **1.264** [5].
(b) X - Y = (-40,000, +10,000 × 5). Incremental IRR = **7.9 percent**, below the MARR of 10 percent (incremental NPV = -$2,092), so the extra $40,000 is not justified: choose **Y** [4].
(c) At MARR = 7 percent the incremental IRR (7.9 percent) exceeds the MARR, so X becomes preferable [1].

**C2.**
(a) Forward: A 0-2; B 2-6; C 2-8; D 6-9; E 8-13 (waits for C); F 13-15; G 15-18. Backward (18): G 15-18; F 13-15; E 8-13; D 10-13; C 2-8; B 4-8; A 0-2. Floats: A 0, B **2**, C 0, D **4**, E 0, F 0, G 0 [5].
(b) Critical path **A-C-E-F-G = 2 + 6 + 5 + 2 + 3 = 18 weeks** [2].
(c) Slopes: C: $3,000/2 weeks = $1,500/week; E: $4,000/2 = $2,000/week. Crash C by 2 weeks ($3,000): the critical path shortens to 16 weeks if no other path becomes critical; the other path A-B-E-F-G = 2 + 4 + 5 + 2 + 3 = 16 weeks, so crashing C by 2 makes both paths critical (16). The cheapest way to save 2 weeks is to crash **C by 2 weeks for $3,000** [3].

**C3.**
(a) CPI = 40/46 = **0.870**; SPI = 40/48 = **0.833**; EAC = BAC/CPI = **$92,000**; EAC = AC + (BAC - EV) = **$86,000**; TCPI = (80,000 - 40,000)/(80,000 - 46,000) = **1.18** [5]. The project is over cost and behind schedule; hitting the budget would require 18 percent better efficiency than the plan, so expect an overrun of $6,000 to $12,000.
(b) σ = 0.55/2.059 = **0.267**; C_p = (26 - 24)/(6 × 0.267) = **1.25**; C_pk = min(26 - 25.017, 25.017 - 24)/(3 × 0.267) = 0.983/0.801 = **1.23**. The process is nearly centred and capable (C_pk below the 1.33 target), so a modest improvement in variation is needed [5].

**B1.** The form is 0/0, so use L'Hôpital twice.
Step 1: differentiate numerator and denominator: (2e^(2x) - 2)/(2x), still 0/0 at x = 0.
Step 2: differentiate again: 4e^(2x)/2 = 2e^(2x).
Step 3: let x → 0: 2e⁰ = **2**.
(Check by Maclaurin: e^(2x) = 1 + 2x + 2x² + ..., so the numerator is 2x² + ... and the ratio is 2.) (2 marks first application, 2 marks second, 1 mark value.)

**B2.** Step 1: take logs: ln y = x ln(sin x).
Step 2: differentiate (product rule on the right): y'/y = ln(sin x) + x · (cos x/sin x).
Step 3: multiply by y: **y' = (sin x)ˣ [ln(sin x) + x cot x]**. (2 marks log, 2 differentiate, 1 solve.)

**B3.** Step 1: differentiate x²y + y³ = 2 implicitly: 2xy + x²y' + 3y²y' = 0.
Step 2: substitute (1, 1): 2 + y' + 3y' = 0, so 4y' = -2.
Step 3: **y' = -1/2**. (Point check: 1² · 1 + 1³ = 2 ✓.) (3 marks differentiation, 2 marks substitution.)

**B4.** Step 1: let u = x³ + 1, du = 3x² dx, so x² dx = du/3. Limits: x = 0 → u = 1; x = 1 → u = 2.

## Section C solutions

**C1.** f(x) = x/(x² + 1).
(a) Step 1: the denominator x² + 1 is never 0, so the domain is all real numbers.
Step 2: f(-x) = -x/(x² + 1) = -f(x), so f is odd (symmetric about the origin).
Step 3: as x → ±∞, f ~ x/x² = 1/x → 0, so y = 0 is a horizontal asymptote; there is no vertical asymptote.
(b) Step 1: quotient rule: f' = [(1)(x² + 1) - x(2x)]/(x² + 1)² = (1 - x²)/(x² + 1)².
Step 2: the denominator is positive, so the sign is that of 1 - x²: f' > 0 on (-1, 1) (increasing) and f' < 0 for |x| > 1 (decreasing).
Step 3: f(1) = 1/2 and f(-1) = -1/2. **Local minimum at (-1, -1/2), local maximum at (1, 1/2).**
(c) Step 1: differentiate f' (quotient rule): f'' = [-2x(x² + 1)² - (1 - x²)(2)(x² + 1)(2x)]/(x² + 1)⁴ = [-2x(x² + 1) - 4x(1 - x²)]/(x² + 1)³ = (-2x³ - 2x - 4x + 4x³)/(x² + 1)³ = (2x³ - 6x)/(x² + 1)³ = 2x(x² - 3)/(x² + 1)³.
Step 2: f'' = 0 at x = 0, ±√3. Sign table: x < -√3: negative; -√3 < x < 0: positive; 0 < x < √3: negative; x > √3: positive.
Step 3: concave up on (-√3, 0) and (√3, ∞); concave down on (-∞, -√3) and (0, √3).
Step 4: f changes concavity at each, so **inflection points at x = -√3, 0, √3**, with f(±√3) = ±√3/4 ≈ ±0.433 and f(0) = 0.
(d) Step 1: let u = x² + 1, du = 2x dx. Limits 0 → 1 and 1 → 2.
Step 2: ∫₀¹ x/(x² + 1) dx = (1/2) ∫₁² du/u = (1/2) ln 2. **(1/2) ln 2 ≈ 0.347**.

**C2.** Let r = radius of the semicircle (so the rectangle's width is 2r) and h = height of the rectangle.
Step 1 (perimeter): base 2r + two sides 2h + semicircle arc πr = 10, so h = (10 - 2r - πr)/2.
Step 2 (area): A = (rectangle) 2r · h + (semicircle) πr²/2 = r(10 - 2r - πr) + πr²/2 = 10r - 2r² - πr² + πr²/2 = 10r - 2r² - πr²/2.
Step 3: A' = 10 - 4r - πr = 0, so **r = 10/(4 + π) ≈ 10/7.1416 = 1.400 m**.
Step 4: A'' = -(4 + π) < 0, so this is a maximum.
Step 5: h = (10 - (2 + π)r)/2. Since (2 + π)r = (2 + π) · 10/(4 + π), h = 10[(4 + π) - (2 + π)]/(2(4 + π)) = 10 · 2/(2(4 + π)) = 10/(4 + π) = r.
Step 6: A_max = 10r - (4 + π)r²/2. With (4 + π)r = 10: A_max = 10r - 10r/2 = 5r = 50/(4 + π) ≈ 7.00 m².
**Width 2r ≈ 2.80 m, rectangle height ≈ 1.40 m (equal to r), maximum area ≈ 7.00 m².** (2 marks setup, 2 area function, 3 optimise, 1 verify max, 2 final values.)

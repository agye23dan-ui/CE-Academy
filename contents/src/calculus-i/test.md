## Section B: Problems (40 marks)

**B1. (10 marks)**
(a) Evaluate lim(x→0) (sqrt(9 + x) - 3)/x. [3]
(b) Using the epsilon-delta definition, prove lim(x→3) (5x - 2) = 13. [3]

**B2. (10 marks)** Let f(x) = x^3 - 3x^2 + 1.
(a) Find all critical points and classify them using the second derivative test. [4]
(b) Find the inflection point. [2]
(c) Show that f has exactly three real roots by using the IVT on suitable intervals. [4]

**B3. (10 marks)** A rectangular farm of area 800 m^2 is fenced on all four sides and divided into two equal parts by a fence parallel to one side. Find the dimensions that minimise the total length of fence. [10]

**B4. (10 marks)** A 10 m ladder leans against a vertical wall. The foot slides away from the wall at 0.5 m/s.
(a) How fast is the top sliding down when the foot is 6 m from the wall? [5]
(b) At that instant, how fast is the angle between the ladder and the ground changing? [5]

## Answer Key and Solutions

### Section A
1. **C** (Step 1: x² - 4 = (x - 2)(x + 2). Step 2: cancel (x - 2) for x ≠ 2, leaving x + 2. Step 3: at x = 2 this is 2 + 2 = 4.)
2. **B** (Step 1: divide top and bottom by x²: (4 + 3/x²)/(2 - 1/x). Step 2: as x → ∞ the terms 3/x² and 1/x → 0, so the limit is 4/2 = 2.)
3. **C** (Step 1: write sin(4x)/x = 4 · sin(4x)/(4x). Step 2: sin(u)/u → 1 as u → 0. Step 3: the limit is 4 · 1 = 4.)
4. **B** (Step 1: (x² - 1)/(x - 1) = x + 1 for x ≠ 1, so the limit at 1 is 2. Step 2: f(1) is undefined, but the limit exists, so the discontinuity is removable.)
5. **C** (Step 1: f'(x) = 3x² - 2. Step 2: f'(2) = 3(4) - 2 = 12 - 2 = 10.)
6. **B** (Chain rule: d/dx sin(u) = cos(u) · u' with u = x², u' = 2x, so the derivative is 2x cos(x²).)
7. **C** (Product rule: (x)'eˣ + x(eˣ)' = eˣ + x eˣ = eˣ(1 + x).)
8. **C** (Step 1: chain rule: (1/(3x)) · 3. Step 2: 3/(3x) = 1/x. Alternatively ln(3x) = ln 3 + ln x, whose derivative is 1/x.)
9. **B** (Step 1: differentiate implicitly: 2x + 2y y' = 0, so y' = -x/y. Step 2: at (3, 4): y' = -3/4.)
10. **A** (Step 1: d/du arctan u = 1/(1 + u²) with u = 2x. Step 2: multiply by u' = 2: 2/(1 + (2x)²) = 2/(1 + 4x²).)
11. **A** (Step 1: y' = 2x, so the slope at x = 3 is 6. Step 2: y(3) = 9. Step 3: y - 9 = 6(x - 3), so y = 6x - 18 + 9 = 6x - 9.)
12. **C** (f is continuous with f(0) = -2 < 1 < 3 = f(1); the IVT guarantees at least one c in (0, 1) with f(c) = 1, but not exactly one.)
13. **B** (For x > 0, |x| = x with slope +1; for x < 0, |x| = -x with slope -1. The one-sided slopes at 0 differ, so the derivative does not exist.)
14. **C** (Step 1: y = x^x, ln y = x ln x. Step 2: y'/y = ln x + x(1/x) = ln x + 1. Step 3: y' = x^x(1 + ln x).)
15. **B** (Second derivative test: f'(c) = 0 and f''(c) = -3 < 0 means concave down at a critical point: a local maximum.)
16. **B** (This is the definition of the derivative of eˣ at 0: (e^h - e⁰)/h → eˣ at x = 0, which equals 1.)
17. **A** (x e^(-x) = x/eˣ; the exponential grows faster than any power of x, so x/eˣ → 0. L'Hôpital: 1/eˣ → 0.)
18. **A** (Step 1: quotient rule: f' = [2x(x - 1) - (x² + 1)(1)]/(x - 1)² = (2x² - 2x - x² - 1)/(x - 1)² = (x² - 2x - 1)/(x - 1)². Step 2: at x = 2: (4 - 4 - 1)/1² = -1.)
19. **A** (Step 1: f(4) = 2. Step 2: f'(x) = 1/(2√x), so f'(4) = 1/4. Step 3: L(x) = 2 + (x - 4)/4.)
20. **B** (Step 1: v = s' = 3t² - 12t + 9 = 3(t² - 4t + 3). Step 2: factor: 3(t - 1)(t - 3). Step 3: v = 0 at t = 1 and t = 3.)

### Section B

**B1.**
(a) Step 1: substituting x = 0 gives 0/0. Multiply by the conjugate: (√(9 + x) - 3)(√(9 + x) + 3) = (9 + x) - 9 = x.
Step 2: the limit becomes lim x/(x(√(9 + x) + 3)) = lim 1/(√(9 + x) + 3).
Step 3: at x = 0: 1/(√9 + 3) = 1/(3 + 3) = **1/6**. (1 mark method, 1 conjugate, 1 answer.)
(b) Step 1 (scratch work): |(5x - 2) - 13| = |5x - 15| = 5|x - 3|. Need 5|x - 3| < ε, i.e. |x - 3| < ε/5.
Step 2: given ε > 0 choose δ = ε/5.
Step 3 (verify): if 0 < |x - 3| < δ, then |(5x - 2) - 13| = 5|x - 3| < 5δ = ε. ∎ (1 mark each for scratch work, δ, verification.)
(c) Step 1: use the identity 1 - cos 2x = 2 sin² x, so f(x) = 2 sin² x/x² = 2 (sin x/x)².
Step 2: as x → 0, sin x/x → 1, so f(x) → 2(1)² = 2.
Step 3: continuity at 0 requires k = lim f(x) = 2. **k = 2**. (2 marks identity, 1 limit, 1 value.)

**B2.** f(x) = x³ - 3x² + 1.
(a) Step 1: f'(x) = 3x² - 6x = 3x(x - 2). Critical points where f' = 0: **x = 0 and x = 2**.
Step 2: f''(x) = 6x - 6.
Step 3: f''(0) = -6 < 0, so x = 0 is a **local maximum**, f(0) = 1, point (0, 1).
Step 4: f''(2) = 12 - 6 = 6 > 0, so x = 2 is a **local minimum**, f(2) = 8 - 12 + 1 = -3, point (2, -3).
(b) Step 1: f''(x) = 6x - 6 = 0 at x = 1.
Step 2: f'' changes sign from negative (x < 1) to positive (x > 1), so it is an inflection point.
Step 3: f(1) = 1 - 3 + 1 = -1. **Inflection point (1, -1)**.
(c) Step 1: evaluate f at test points: f(-1) = -1 - 3 + 1 = -3, f(0) = 1, f(1) = -1, f(2) = -3, f(3) = 27 - 27 + 1 = 1.
Step 2: sign changes: f(-1) < 0 < f(0) gives a root in (-1, 0); f(0) > 0 > f(1) gives a root in (0, 1); f(2) < 0 < f(3) gives a root in (2, 3).
Step 3: the three intervals are disjoint and f is continuous (IVT), so there are at least three roots; a cubic has at most three. So **exactly three real roots**.

**B3.** Setup: the fence has three segments of length x (two outer sides and the divider) and two segments of length y.
Step 1: area xy = 800, so y = 800/x.
Step 2: total length L = 3x + 2y = 3x + 1600/x.
Step 3: L' = 3 - 1600/x² = 0 gives x² = 1600/3, x = 40/√3 ≈ 23.09 m.
Step 4: y = 800/x = 800√3/40 = 20√3 ≈ 34.64 m.
Step 5: L'' = 3200/x³ > 0, so this is a minimum.
Step 6: L = 3x + 2y = 3(40/√3) + 2(20√3) = 40√3 + 40√3 = 80√3 ≈ 138.6 m (using 3/√3 = √3).
**Dimensions: 40/√3 ≈ 23.1 m for each of the three parallel fences, and 20√3 ≈ 34.6 m for the other two sides; minimum fence 80√3 ≈ 138.6 m.** (2 marks setup, 2 length function, 3 derivative and solve, 2 justify minimum, 1 dimensions.)

**B4.** Let x = distance of the foot from the wall and y = height of the top: x² + y² = 100. Given dx/dt = 0.5 m/s.
(a) Step 1: differentiate: 2x x' + 2y y' = 0, so y' = -x x'/y.
Step 2: at x = 6: y = √(100 - 36) = √64 = 8.
Step 3: y' = -(6)(0.5)/8 = -3/8.
**y' = -0.375 m/s** (the top slides down at 0.375 m/s).
(b) Step 1: cos θ = x/10. Differentiate: -sin θ θ' = x'/10 = 0.05.
Step 2: sin θ = y/10 = 0.8.
Step 3: θ' = -0.05/0.8 = -0.0625.
**θ' = -0.0625 rad/s** (the angle decreases at 1/16 rad/s ≈ 3.6°/s).
